# 🎬 Páginas de Filmes

Projeto acadêmico em HTML e CSS onde cada integrante da equipe criou uma página apresentando um filme escolhido, com informações, imagens e curiosidades sobre a obra.

## 👥 Equipe

- **Guilherme** — Esquadrão Suicida
- **Miguel Matias** — O Resgate do Soldado Ryan
- **Yuji** — Star Wars III: A Vingança dos Sith
- **Leonardo** — Homem-Aranha: Sem Volta Para Casa

## 📄 Páginas do site

| Página | Filme |
|---|---|
| `index.html` | Página inicial com o menu de acesso às páginas de cada filme |
| `paginas/aluno-guilherme.html` | Esquadrão Suicida |
| `paginas/aluno-miguelmatias.html` | O Resgate do Soldado Ryan |
| `paginas/aluno-yuji.html` | Star Wars III: A Vingança dos Sith |

## 🚀 Como abrir o site

1. Faça o clone ou download deste repositório:
   ```bash
   git clone https://github.com/Klauz-code/site-da-equipe.git
   ```
2. Entre na pasta do projeto.
3. Abra o arquivo `index.html` diretamente no navegador de sua preferência (duplo clique ou clique com o botão direito e "Abrir com").
4. A partir da página inicial, navegue até a página de cada filme através dos links do menu.

> Não é necessário nenhum servidor ou instalação — o site funciona totalmente abrindo os arquivos `.html` no navegador.
